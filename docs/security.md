# Security and limitations

Mock execution does not access the network and never executes proposed tool calls. Provider adapters make requests only when their provider kinds are selected in a contract. The runner reads the contract's fixture and schema files and writes reports under the selected output directory. Response payloads and proposed tool arguments are redacted by default in attempt records; assertion actual values are omitted by default. `--include-content` stores prompts and model content and should be used only with authorized local data. Credentials are read from environment variables and are not written to artifacts. HTML strings and assertion values are escaped before rendering.

LLM Fallback Compatibility Tester is a testing harness, not a production monitoring system. HTTP requests have configured timeouts, and runs apply per-attempt limits plus an optional overall deadline. Cost limits can be evaluated when provider cost data is available; live API cost is normally unknown and is reported as inconclusive. Assertions cover declared deterministic rules and do not claim arbitrary semantic understanding. A passing sample does not prove correctness for future inputs.
